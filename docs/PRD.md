# RIGHT NOW — Product Brief (Phase 1)

**Name:** RIGHT NOW (future: Prayify)  
**Tagline:** Whatever you're going through, start here.  
**Core loop:** FEEL → WORD → PRAYER

## Non-negotiables
- Never claim AI knows God’s will; label AI prayers as AI-generated
- Never replace clergy, Scripture authority, medical/mental-health care, or emergency services
- Never fabricate Bible verses — only verified public-domain / licensed text
- Free Bible + basic prayer must remain usable without paywall
- Brand: peaceful, premium, trustworthy — charcoal / ivory / muted gold

## Phase 1 (this build)
Auth stub/guest · Home · Feeling → Scripture · Prayer (template + optional speak) · Bible reader (WEB/KJV) · Search · Highlights/bookmarks (local) · Daily verse · Streaks · Morning/Night stubs · Profile basics

## Later
Plans, journal, community, sleep mode, premium, churches, marketplace — see full user brief.
